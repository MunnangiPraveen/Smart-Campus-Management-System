# 🎓 Smart Campus Management System

A full-stack web application designed to simplify and automate campus management activities. The system provides a centralized platform for managing students, faculty, courses, attendance, notices, and other campus-related operations efficiently.

---

## 🚀 Features

- 👨‍🎓 Student Management
  - Student registration
  - Profile management
  - View enrolled courses

- 👨‍🏫 Faculty Management
  - Faculty registration
  - Manage assigned courses
  - Update student records

- 📚 Course Management
  - Add, update, and delete courses
  - Course enrollment
  - Course information management

- 📅 Attendance Management
  - Mark attendance
  - View attendance history
  - Attendance reports

- 📢 Notice Board
  - Publish campus announcements
  - View latest notices

- 🔐 Authentication
  - Secure Login
  - Role-based access
  - Session management

- 📊 Dashboard
  - Campus statistics
  - Quick access to important modules
